CfTunnelTool 使用說明
====================

CfTunnelTool 用 Cloudflare Tunnel 做兩件事：
  - 對外網址：讓外網用你自己的網域（例如 https://api.yourdomain.com）
    連到這台電腦上的網站和 API
  - 遠端桌面：讓使用者從外面連到公司內的電腦，連線前要先通過 Email 驗證碼和 2FA

不需要固定 IP、不用設定路由器，遠端桌面連接埠完全不對外。

■ 一、系統需求與執行方式

  系統需求：
  - Windows 10 / 11（64 位元），不需要安裝 .NET
  - 中繼電腦：一個已經加入 Cloudflare 的網域、可以連上網際網路、一直開機
  - 被連線的電腦：Windows 專業版 / 企業版 / Server（家用版不能當遠端桌面主機），
    固定 IP 或在路由器做 DHCP 保留

  執行方式：
  1. 把 zip 解壓縮到任何位置，按兩下 CfTunnelTool.exe
  2. 出現藍色視窗「Windows 已保護您的電腦」時，按「其他資訊」→「仍要執行」
     （程式沒有購買程式碼簽章，不是病毒）
  3. Windows 詢問是否允許變更時，按「是」


■ 二、選擇模式

  第一次執行時會詢問要做什麼：

    我是管理者               公司內一直開機的那台電腦（中繼電腦），需要 Cloudflare 帳號
    我要連到公司的電腦       在外面要連回公司的使用者
    這台電腦要被遠端連線     公司內要讓別人連進來的電腦

  只有「我是管理者」需要管理帳號密碼，另外兩種不需要。


■ 三、管理者：部署中繼電腦

  1. 準備 Cloudflare：
     - 網域已加入 Cloudflare
     - 要用遠端桌面時，先到 https://one.dash.cloudflare.com/ 啟用 Zero Trust
       （依畫面設定 team 名稱、選擇 Free 方案，最多 50 位使用者）

  2. 選「我是管理者」，先設定管理帳號密碼（見第四章），再跟著精靈完成 5 個步驟：

     步驟 1  API Token
             按「開啟 Cloudflare Token 頁面」，依畫面上的權限表建立 Token：
               必要      Account → Cloudflare Tunnel → Edit
                         Zone    → DNS               → Edit
                         Zone    → Zone              → Read
               遠端桌面  Account → Access: Apps and Policies → Edit
                         Account → Access: Organizations, Identity Providers, and Groups → Edit
                         Account → Zero Trust → Edit
               紀錄      Account → Access: Audit Logs → Read
                         Account → Account Analytics → Read
             貼上後按「驗證 Token」。中繼電腦建議不要勾選「記住這組 Token」。

     步驟 2  選擇網域，設定 Tunnel 名稱（預設為電腦名稱；多個地點要用不同名稱）

     步驟 3  對外網址，例如 api → http://localhost:5000（只用遠端桌面可以不設）

     步驟 4  遠端桌面（選用）
             - 勾選「啟用遠端桌面（RDP）＋ 2FA」
             - 連線方式：WARP（建議，最流暢）、瀏覽器（免安裝），可以兩種都開
             - 要開放的電腦：「加入這台電腦」或「新增區網電腦」（填區網 IP）
             - 允許登入的 Email：一行一個；@公司網域.com 代表整個網域
             - 2FA 方式：Authenticator App、安全金鑰、生物辨識
             - 2FA 有效時間：每次連線（預設）／1 小時／8 小時／24 小時
             - Email 驗證碼有效時間：1 小時／8 小時（預設）／24 小時／7 天
               （整個 Cloudflare 帳號共用；在這段時間內重新連線，只需要再做 2FA）
             - 瀏覽器方式的剪貼簿、檔案上傳、檔案下載權限

     步驟 5  按「開始部署」，約 1 分鐘。下方記錄每一行都應該是 ✓；
             有 ⚠ 的項目請照訊息處理後按「重新部署」。

  3. 完成頁按「複製連線資訊（給使用者）」，把內容傳給使用者。
     內容包含連線代碼（CFT1: 開頭）、瀏覽器連線網址、「註冊 2FA 裝置」網址，不含任何密碼。

  部署完成後，開始功能表與桌面會出現「CfTunnelTool」捷徑，之後用它開啟管理畫面。
  連線服務是 Windows 服務，關閉程式或重新開機都不影響連線。

  部署時程式在 Cloudflare 自動完成：
  - Tunnel、DNS 紀錄、私有網路路由（每台電腦一條 /32）
  - Email 驗證碼登入、組織 2FA、Access 應用程式與政策
  - WARP 裝置註冊權限：只有允許的 Email、而且通過 2FA 才能把電腦加入組織
  - Gateway TCP／UDP 代理與 Split Tunnel：只讓被開放的電腦 IP 走 WARP
  - Gateway 網路規則：被開放的電腦只開放遠端桌面連接埠，其他連接埠（例如 445 檔案分享）一律封鎖
  - 中繼電腦本身在開放清單中時：遠端桌面防火牆只允許內部網路、開啟 NLA

  從舊版升級：用新版重新部署每一個地點，才會套用最新的 Cloudflare 設定。


■ 四、管理者：管理畫面與管理帳號密碼

  管理畫面：
  - 查看連線服務與 Tunnel 狀態，測試每個網址與遠端桌面連接埠
  - 複製 RDP 連線資訊、修改設定（回到精靈）、重新啟動連線服務、紀錄
  - 移除全部設定：只刪除這台電腦建立的 Cloudflare 資源與本機服務

  管理帳號密碼：
  - 第一次進入管理畫面時設定帳號與密碼（密碼至少 10 個字元，不能和帳號相同）
  - 之後每次開啟管理畫面都要登入
  - 連續輸入錯誤 5 次，鎖定 5 分鐘（重開程式也不會解除）
  - 閒置 15 分鐘自動鎖定，要重新登入（部署等背景工作不會中斷）
  - 管理畫面按「變更管理密碼…」，輸入目前密碼後設定新密碼
  - 從「設定 → 應用程式」解除安裝時也要先登入

  忘記管理密碼：
  1. 登入畫面按「忘記密碼…」
  2. 輸入這個地點的 Cloudflare API Token（要手動輸入；已儲存的 Token 不能用來重設）
  3. 程式確認 Token 能存取這個網域與 Tunnel 後，重新設定帳號密碼
  刪除 admin.dat 也一樣要經過這個驗證。

  從舊版升級的電腦，第一次開啟管理畫面會先要求 Cloudflare 驗證，再設定帳號密碼，
  請事先準備好 API Token。


■ 五、使用者：第一次連線

  登入順序：Email 驗證碼 → 2FA → Windows 帳號密碼

  WARP ＋ 遠端桌面連線（建議，支援聲音、多螢幕、印表機）：
  1. 在自己的電腦執行 CfTunnelTool.exe，選「我要連到公司的電腦」
  2. 貼上管理者給的連線資訊，按「安裝並加入組織」
  3. 程式會從 Cloudflare 官方網站下載安裝 WARP；WARP 開啟登入畫面後輸入 Email、
     收信取得驗證碼；第一次會要求註冊 2FA（例如用手機 Authenticator App 掃描 QR Code）
  4. 桌面會出現「遠端桌面 - 電腦名稱」捷徑，點它連線（不會跳出系統管理員確認），
     輸入公司那台電腦的 Windows 帳號密碼（帳號格式：電腦名稱\帳號）

  連線前自動驗證：
  - 按捷徑或程式裡的「連線」時，程式會先測試連不連得到
  - 需要重新驗證（2FA 到期）時，會自動開啟驗證網頁，並跳出「需要重新驗證 2FA」視窗提醒
  - 在瀏覽器輸入 Email 驗證碼與 2FA，完成後視窗自動關閉、自動開啟遠端桌面
  - 驗證頁被關掉時按「重新開啟驗證頁」；最多等 3 分鐘，逾時會列出可能原因
  - 舊版建立的桌面捷徑，開啟 CfTunnelTool 使用者畫面時會自動換成新捷徑

  之後從開始功能表的「CfTunnelTool」開啟使用者畫面：
  - 我的連線：新增、編輯、刪除電腦，點兩下連線；「測試全部」檢查哪些電腦連得到
  - 加入公司／匯入連線代碼：管理者新增電腦後，匯入新的連線代碼會自動合併
  - 中斷連線：不需要連公司時中斷 WARP，平常上網就不會經過公司
  - 2FA 狀態：顯示是否有效、大約何時到期；也可以按「立即重新驗證」提前驗證
    （2FA 到期後，已連上的遠端桌面不會中斷，只有新的連線需要重新驗證）
  - 移除這個公司連線：登出 WARP 組織、刪除清單與捷徑，可一併解除安裝 WARP

  瀏覽器（免安裝，畫面較慢）：
  1. 開啟管理者提供的「註冊 2FA 裝置」網址，用 Email 驗證碼登入，註冊 2FA
  2. 之後開啟各台電腦的連線網址，依序輸入 Email 驗證碼、2FA、Windows 帳號密碼
  限制：剪貼簿單次 500 KB、不能複製圖片、沒有聲音、檔案傳輸為 Cloudflare 的 Beta 功能。


■ 六、被連線的電腦

  在要開放的電腦執行 CfTunnelTool.exe，選「這台電腦要被遠端連線」。
  不需要 Cloudflare 帳號，也不用部署；請把這台電腦的區網 IP 告訴管理者加入清單。

  這台電腦的遠端桌面：
  - 按「啟用這台電腦的遠端桌面」，同時會限制防火牆來源並開啟 NLA

  防火牆來源：
  - 應顯示「✓ 只允許內部網路」
  - 顯示 ✗ 允許任何來源時，按「只允許內部網路連線」：遠端桌面只接受同網段與私有 IP
    （10.x／172.16–31.x／192.168.x）。經 Cloudflare 連進來不受影響；
    路由器轉送、DMZ、UPnP 或電腦直接拿到公網 IP 時，網際網路的暴力破解會被擋掉

  NLA（網路層級驗證）：
  - 開啟這個畫面時會自動開啟，帳號密碼驗證通過才建立遠端桌面工作階段
  - 顯示紅字「群組原則強制關閉」時，程式不會覆寫，請照畫面上的路徑修改：
      gpedit.msc → 電腦設定 → 系統管理範本 → Windows 元件 → 遠端桌面服務
      → 遠端桌面工作階段主機 → 安全性
      →「需要使用網路層級驗證對遠端連線進行使用者驗證」設為「已啟用」或「尚未設定」，
      並確認「遠端 (RDP) 連線需要使用指定的安全性層」不是「RDP」
    網域電腦請洽 IT 修改網域原則
  - 加入 Microsoft Entra ID 的電腦：用瀏覽器方式登入需要關閉 NLA，
    但程式會強制開啟 NLA，請改用 WARP 方式連線

  遠端登入密碼：
  - 空白密碼的 Windows 帳號不能遠端登入
  - 選擇帳號、輸入新密碼（至少 8 個字元），按「設定密碼」；
    勾選「保留開機自動登入」，在電腦前面使用時仍然不用輸入密碼
    （自動登入的密碼由 Windows 加密保存）
  - 遠端登入時，帳號輸入「電腦名稱\帳號」（畫面會顯示正確格式）
  - Microsoft 帳號：帳號輸入 MicrosoftAccount\信箱，密碼輸入 Microsoft 帳號密碼（不是 PIN）
  - 網域、Entra ID 帳號的密碼由公司管理，無法在這裡設定
  - 建議另外設定 Windows Hello PIN：在電腦前面登入時只要輸入 PIN（PIN 不能用來遠端登入）

  結束遠端並交還畫面：
  - 按「在桌面建立『結束遠端並交還畫面』捷徑」
  - 遠端使用者離開前雙擊這個捷徑（不要直接按 ✕），電腦前面的螢幕會直接回到桌面
  - 會跳出系統管理員確認，按「是」；遠端登入的帳號需要是系統管理員
  - 交還後螢幕是未鎖定的，電腦放在公共區域時請斟酌使用


■ 七、多個地點

  - 每個地點各放一台中繼電腦，使用不同的 Tunnel 名稱、同一個 Cloudflare 帳號
  - 2FA 註冊入口與 WARP 註冊權限整個帳號共用；各地點部署時只加入自己的 Email，
    移除時也只移除自己的部分
  - 使用者匯入多個地點的連線代碼，會合併成同一份連線清單

  不同地點的內網 IP 相同（例如兩個廠區都有 192.168.1.10）：
  - 在每個地點的精靈「遠端桌面」步驟勾選「這個地點使用獨立的虛擬網路」
  - 程式會建立「cft-Tunnel名稱」虛擬網路，該地點的路由與目標都放在裡面
  - 瀏覽器方式：連線網址本來就包含地點，可以同時使用
  - WARP 方式：同一時間只能連一個地點；連線時程式會自動切換，
    連到另一個地點的遠端桌面會中斷
  - 已部署的地點改成勾選後要重新部署，使用者需重新匯入新的連線代碼
  - 只有一個地點，或各地點網段都不同時，不需要勾選


■ 八、紀錄

  開啟方式：
  - 管理畫面按「紀錄…」
  - 被連線的電腦在「這台電腦要被遠端連線」畫面按「查看與設定使用紀錄…」
  - 使用者畫面按「紀錄…」（只有程式操作紀錄）

  紀錄種類：
  - 登入：誰（Email）、何時、從哪個 IP、登入哪個服務、允許或擋下（Cloudflare Access）
  - 遠端桌面使用：哪個 Windows 帳號何時連入、中斷、登出、使用多久、登入失敗（Windows 事件）
  - 網路傳輸：WARP 使用者連到哪台電腦、大約傳輸多少資料（Cloudflare Gateway 抽樣統計）
  - 程式操作：部署、修改、移除、連線、管理畫面登入與變更密碼等

  自動收集：
  - Cloudflare 免費方案的登入與網路紀錄只保留 24 小時，請按「啟用每小時自動收集」
  - 建立的 Windows 排程以 SYSTEM 身分每小時執行，不需要登入；請讓電腦保持開機
  - 紀錄存在 C:\ProgramData\CfTunnelTool\logs（只有系統管理員能讀取），預設保留 365 天
  - 可依日期與文字篩選，並「匯出 CSV」用 Excel 開啟

  限制：
  - 遠端桌面使用紀錄只記錄執行收集的那台電腦；其他電腦要在該電腦上啟用
  - 遠端桌面使用紀錄的來源 IP 是中繼電腦，使用者身分請對照同時間的登入紀錄
  - 瀏覽器方式的檔案傳輸，Cloudflare 沒有提供檔案名稱紀錄


■ 九、資安提醒

  外部的人要連到遠端桌面，必須同時取得：使用者的 Email 信箱、2FA 裝置、
  被連電腦的 Windows 帳號密碼。剩下的風險在以下幾處，請管理者自行加強：

  1. 中繼電腦：Windows 帳號用強密碼、保持更新、開防毒；不要拿來上網或收信。
     能登入這台電腦系統管理員的人就能控制整套設定，管理密碼只是多一道門
  2. Cloudflare 帳號、使用者的 Email 信箱都要開啟 2FA；
     API Token 只給需要的權限並設定到期日
  3. 允許清單盡量列個別 Email，少用「@公司網域.com」
  4. 路由器不要轉發 3389，並關閉 UPnP
  5. 被連電腦的 Windows 帳號用強密碼；內部網路的電腦仍可直接嘗試登入遠端桌面
  6. 啟用紀錄自動收集並定期查看；遠端桌面紀錄出現「公網 IP」的登入失敗，
     代表這台電腦被直接暴露在網際網路上
  7. 有敏感資料時，關閉瀏覽器方式的檔案下載
  8. 網站和 API 公開後任何人都能連線，請務必做好登入驗證；只給內部使用的網址，
     可以在 Cloudflare → Zero Trust → Access → Applications 加上登入保護


■ 十、常見問題

  Q：忘記管理密碼？
  A：登入畫面按「忘記密碼…」，輸入這個地點的 Cloudflare API Token 重設（見第四章）。

  Q：管理畫面顯示鎖定？
  A：連續錯誤 5 次會鎖定 5 分鐘，時間到後再試；重開程式不會解除。

  Q：每次連線都要輸入 Email 驗證碼？
  A：部署後要按一次「重新部署」才會套用有效時間；瀏覽器請保留 cloudflareaccess.com
     的 Cookie（不要用無痕視窗）。2FA 選「每次連線」時，每次都要做 2FA 是正常的。

  Q：連線時跳出「需要重新驗證 2FA」，但沒有看到驗證網頁？
  A：按視窗裡的「重新開啟驗證頁」；仍然沒有出現時，點右下角 WARP 圖示 →
     個人資料 → 帳戶資訊 → 重新驗證。完成後等候視窗會自動連線。

  Q：WARP 連不到公司的電腦？
  A：1. 使用者畫面確認 WARP 為「已連線」、2FA 有效；到期就按「立即重新驗證」
     2. 管理畫面確認 Tunnel 已連線、該電腦連接埠測試正常
     3. 被連線的電腦確認遠端桌面已啟用、防火牆來源為「只允許內部網路」

  Q：遠端桌面顯示帳號密碼錯誤？
  A：帳號要輸入「電腦名稱\帳號」；空白密碼的帳號不能遠端登入，請先在
     「這台電腦要被遠端連線」設定密碼。Microsoft 帳號要輸入密碼，不是 PIN。

  Q：NLA 顯示「群組原則強制關閉」？
  A：照第六章的 gpedit 路徑修改；網域電腦請洽 IT。

  Q：紀錄裡出現公網 IP 的登入失敗？
  A：代表有人繞過 Cloudflare 直接連到這台電腦。在「這台電腦要被遠端連線」
     按「只允許內部網路連線」，並檢查路由器的連接埠轉送、DMZ、UPnP。

  Q：Tunnel 無法連線？
  A：管理畫面按「重新啟動連線服務」；仍無法連線時開啟
     「事件檢視器 → Windows 記錄 → 應用程式」，找來源為 cloudflared 的錯誤訊息。

  回報問題時請提供：
  1. 部署頁或管理畫面下方「記錄」視窗的截圖
  2. 跳出的錯誤訊息截圖
  3. 紀錄視窗「程式操作」頁匯出的 CSV

  [ ] 管理畫面顯示連線服務執行中、Cloudflare Tunnel 已連線
