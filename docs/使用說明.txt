CfTunnelTool 使用說明
====================

讓外網透過你自己的網域（例如 https://api.yourdomain.com）連到這台電腦上的網站和 API。
不需要固定 IP、不用設定路由器，Cloudflare 會自動提供 HTTPS。


■ 系統需求
  - Windows 10 / 11（64 位元）
  - 一個已經加入 Cloudflare 的網域
  - 這台電腦可以連上網際網路
  - 不需要安裝 .NET（已包含在執行檔內）


■ 執行方式
  1. 把 CfTunnelTool.exe 解壓縮到任何位置（例如桌面）
  2. 按兩下 CfTunnelTool.exe
  3. 如果出現藍色視窗「Windows 已保護您的電腦」：
       按「其他資訊」→「仍要執行」
     （原因是這個程式沒有購買程式碼簽章，不是病毒）
  4. Windows 詢問是否允許變更時，按「是」（需要系統管理員權限才能安裝連線服務）
  5. 跟著畫面上的精靈完成 5 個步驟：
       步驟 1  建立 Cloudflare API Token（畫面上有詳細教學與權限表）
       步驟 2  選擇網域、設定這台電腦的 Tunnel 名稱
       步驟 3  設定對外網址，例如 api → http://localhost:5000（只用遠端桌面可以不設）
       步驟 4  （選用）遠端桌面 RDP ＋ 2FA，見下方說明
       步驟 5  按「開始部署」，等待約 1 分鐘

  完成後，開始功能表與桌面會出現「CfTunnelTool」捷徑，之後用它開啟管理畫面。

  管理帳號密碼（1.8.0 起）：
  - 第一次進入管理畫面時設定帳號與密碼（密碼至少 10 個字元），之後每次開啟管理畫面都要登入
  - 連續輸入錯誤 5 次鎖定 5 分鐘；閒置 15 分鐘自動鎖定，要重新登入
  - 管理畫面按「變更管理密碼…」可以更換密碼
  - 忘記密碼：登入畫面按「忘記密碼…」，輸入這個地點的 Cloudflare API Token，驗證通過後設定新帳號密碼
    （Token 只用來驗證，不會儲存；已儲存的 Token 不能用來重設）
  - 從舊版升級的電腦，第一次開啟會先要求 Cloudflare 驗證，再設定帳號密碼
  - 只保護管理畫面；「我要連到公司的電腦」與「這台電腦要被遠端連線」不需要登入


■ 遠端桌面（RDP ＋ 2FA）
  讓使用者從外面連到這台電腦或區網內其他電腦的遠端桌面，有兩種連線方式，可以同時開啟：

    WARP ＋ 遠端桌面連線（建議）：最流暢，支援聲音、多螢幕、印表機；
                                   使用者電腦需安裝 Cloudflare WARP（CfTunnelTool 可自動安裝）
    瀏覽器：免安裝任何軟體，但畫面較慢；適合偶爾使用或外部人員

  登入順序：Email 驗證碼 → 2FA（Authenticator App / 安全金鑰 / 生物辨識）→ Windows 帳號密碼。

  Email 驗證碼和 2FA 的有效時間分開設定（v1.7.1 起）：
    - Email 驗證碼：預設每 8 小時輸入一次（可選 1 小時／8 小時／24 小時／7 天）。
      這是 Zero Trust 組織的「全域登入時間」，同一個 Cloudflare 帳號的所有應用程式共用。
    - 2FA：預設「每次連線都要驗證」。在 Email 驗證碼有效時間內重新連線，只需要再做 2FA。
    - 部署後需要按一次「重新部署」才會套用；使用者端若仍每次要求 Email，
      請在瀏覽器保留 cloudflareaccess.com 的 Cookie（不要用無痕視窗）。

  管理者設定：
  1. API Token 需要額外三個權限（精靈的權限表標示為「遠端桌面」的三列）：
       Account → Access: Apps and Policies → Edit
       Account → Access: Organizations, Identity Providers, and Groups → Edit
       Account → Zero Trust → Edit
  2. Cloudflare 帳號需要先啟用 Zero Trust（免費方案即可）：
       到 https://one.dash.cloudflare.com/ 依畫面設定 team 名稱、選擇 Free 方案
  3. 在精靈「遠端桌面」步驟：
       - 勾選「啟用遠端桌面（RDP）＋ 2FA」，選擇連線方式（WARP、瀏覽器，或兩種都開）
       - 按「加入這台電腦」，或新增區網其他電腦（填該電腦的區網 IP）
       - 輸入允許登入的 Email（一行一個；@公司網域.com 代表整個網域）
       - 選擇 2FA 方式與重新驗證間隔、Email 驗證碼有效時間、剪貼簿與檔案傳輸權限
  4. 部署完成後，在完成頁或管理畫面按「複製連線資訊」，貼給使用者

  使用者第一次使用（WARP ＋ 遠端桌面連線）：
  1. 在自己的電腦執行 CfTunnelTool.exe，選「我要連到公司的電腦」
  2. 貼上管理者給的連線資訊（含 CFT1: 開頭的連線代碼，不含任何密碼），按「安裝並加入組織」
  3. 程式會從 Cloudflare 官方網站下載安裝 WARP；WARP 開啟登入畫面後輸入 Email、
     收信取得驗證碼，第一次會要求註冊 2FA（例如用手機 Authenticator App 掃描 QR Code）
  4. 桌面會出現「遠端桌面 - 電腦名稱」捷徑，點它連線，輸入公司那台電腦的 Windows 帳號密碼
  5. 連線時右下角若跳出「Authentication required」通知，點它完成 2FA 後再連一次

  使用者畫面的功能（之後從開始功能表的「CfTunnelTool」開啟）：
  - 我的連線：可新增、編輯、刪除公司的電腦（名稱、內網 IP、連接埠、預設帳號），
    點兩下連線，會記錄上次連線時間；「測試全部」可一次檢查哪些電腦連得到
  - 匯入連線代碼：管理者新增電腦後，再匯入新的連線代碼會自動合併進清單
  - 中斷連線／重新連線：不需要連公司時中斷 WARP，平常上網就不會經過公司的 Cloudflare
  - 2FA 狀態：顯示 2FA 是否有效、大約何時到期、多久要驗證一次；
    連不到時會提示重新驗證，完成後自動再試；也可以按「立即重新驗證」
    （2FA 到期後，已經連上的遠端桌面不會中斷，只有新的連線需要重新驗證）
  - 移除這個公司連線：登出 WARP 組織、刪除清單與桌面捷徑，可選擇一併解除安裝 WARP

  使用者第一次使用（瀏覽器）：
  1. 開啟管理者提供的「註冊 2FA 裝置」網址，用 Email 驗證碼登入
  2. 依畫面註冊 2FA（例如用手機 Google / Microsoft Authenticator 掃描 QR Code）
  3. 之後開啟各台電腦的連線網址，依序輸入 Email 驗證碼、2FA 驗證碼、Windows 帳號密碼

  WARP 模式在 Cloudflare 上會自動調整：
  - 開啟 Gateway 的 TCP／UDP 代理
  - 裝置註冊權限：只有允許的 Email、而且通過 2FA 才能把電腦加入組織
    （使用者請先到「註冊 2FA 裝置」網址註冊好 2FA，再登入 WARP）
    （1.7.1 以前部署的地點只檢查 Email，請用新版重新部署每個地點）
  - Split Tunnel：讓被開放的電腦 IP（/32）走 WARP（拆開預設排除的 192.168.0.0/16 等私有網段）
  - 私有網路應用程式：連線前要通過 Email ＋ 2FA
  - Gateway 網路規則：被開放的電腦只開放遠端桌面連接埠，其他連接埠（例如 445 檔案分享）一律封鎖
    （規則名稱「CfTunnelTool 只開放遠端桌面 - Tunnel名稱」，每個地點一條；1.7.2 以前部署的地點請重新部署）
  以上會套用到整個帳號的預設 WARP 設定，但只影響被開放的那幾個 IP。

  多個地點（例如不同廠區）：
  - 每個地點各放一台中繼電腦執行 CfTunnelTool，使用不同的 Tunnel 名稱，同一個 Cloudflare 帳號
  - 2FA 註冊入口（App Launcher）與 WARP 註冊權限整個帳號只有一個，
    各地點部署時會自動把自己允許的 Email 加進去，不會覆蓋其他地點
  - 某個地點移除設定時，只會移除該地點的 Email；沒有其他地點使用時才刪除
  - 使用者匯入多個地點的連線代碼，會合併成同一份連線清單

  不同地點的內網 IP 相同（例如兩個廠區都有 192.168.1.10）：
  - 在每個地點的精靈「遠端桌面」步驟勾選「這個地點使用獨立的虛擬網路」
  - 程式會建立名為「cft-Tunnel名稱」的虛擬網路，該地點的路由與目標都放在裡面，彼此不衝突
  - 瀏覽器方式：每台電腦的連線網址本來就包含地點，可以同時使用
  - WARP 方式：同一時間只能連一個地點；使用者端的連線清單有「地點」欄位，
    連線時程式會自動把 WARP 切換到該地點（切換時，連到另一個地點的遠端桌面會中斷）
  - 已經部署的地點改成勾選後重新部署，程式會把路由搬到新的虛擬網路；使用者需重新匯入新的連線代碼
  - 只有一個地點，或各地點網段都不同時，不需要勾選

  被連線的電腦（區網內的其他電腦）：
  - 在那台電腦執行 CfTunnelTool.exe，選「這台電腦要被遠端連線」，
    就能啟用遠端桌面、設定遠端登入密碼、建立「結束遠端並交還畫面」捷徑；
    不需要 Cloudflare 帳號，也不用部署
  - 「防火牆來源」顯示 ✗ 允許任何來源時，請按「只允許內部網路連線」：
    遠端桌面只接受同網段與私有 IP（10.x／172.16–31.x／192.168.x），經 Cloudflare 連進來不受影響，
    路由器轉送、DMZ、UPnP 或電腦直接拿到公網 IP 時，網際網路的暴力破解會被擋掉
    （1.7.4 起「啟用遠端桌面」與中繼電腦部署時會自動限制；紀錄裡出現公網 IP 的登入失敗，就是有這個漏洞）
  - NLA（網路層級驗證）：1.8.0 起開啟這個畫面、啟用遠端桌面、中繼電腦部署時會自動開啟，
    帳號密碼驗證通過才建立遠端桌面工作階段；群組原則強制關閉 NLA 時程式不會覆寫，
    畫面會顯示紅字與 gpedit 的修改路徑（網域電腦請洽 IT）

  結束遠端並交還畫面：
  - 遠端使用者離開前，雙擊桌面上的「結束遠端並交還畫面」（不要直接按 ✕），
    電腦前面的螢幕會直接回到桌面，不需要再輸入 PIN 或密碼
  - 會跳出系統管理員確認，按「是」；遠端登入的帳號需要是系統管理員
  - 交還後螢幕是未鎖定的，電腦放在公共區域時請斟酌使用

  Windows 帳號密碼：
  - 遠端桌面一定要用「有密碼」的 Windows 帳號登入，空白密碼的帳號會被 Windows 拒絕
  - 程式設定密碼時只要求至少 8 個字元
  - 建議另外設定 Windows Hello PIN：登出或鎖定後在電腦前面只要輸入 PIN（PIN 不能用來遠端登入）
  - 原本是空白密碼、開機自動登入的電腦：在精靈「遠端桌面」步驟下方的
    「這台電腦的遠端登入密碼」設定密碼，並勾選「保留開機自動登入」，
    在電腦前面使用時仍然不用輸入密碼（自動登入的密碼由 Windows 加密保存）
  - 遠端登入時，帳號輸入「電腦名稱\帳號」（程式畫面會顯示正確格式）
  - Microsoft 帳號：帳號輸入 MicrosoftAccount\信箱，密碼輸入 Microsoft 帳號密碼（不是 PIN）

  被開放的電腦需要：
  - Windows 專業版 / 企業版 / Server（家用版不能當遠端桌面主機）
  - 已啟用遠端桌面（精靈可以一鍵啟用這台電腦）
  - 固定 IP，或在路由器做 DHCP 保留
  - 加入 Microsoft Entra ID 的電腦，需要關閉遠端桌面的 NLA 強制要求

  瀏覽器方式的限制：剪貼簿單次 500 KB、不能複製圖片、沒有聲音、畫面較慢、檔案傳輸為 Beta 功能。
  需要聲音、多螢幕或更流暢的畫面時，請使用 WARP ＋ 遠端桌面連線。


■ 驗證清單（建議第一次部署時逐項確認）
  [ ] 用手機「行動網路」（不要連同一個 Wi-Fi）開啟設定的網址，可以看到網站 / API
  [ ] 管理畫面顯示「本機連線服務：執行中」、「Cloudflare Tunnel：已連線」
  [ ] 重新開機後，不開 CfTunnelTool，網址仍然可以連線
  [ ] 管理畫面按「修改設定…」新增一個網址並重新部署，新網址可以連線
  [ ] （遠端桌面）用另一個 Email 帳號開啟連線網址，確認不在允許清單的人無法登入
  [ ] （遠端桌面）允許的使用者第一次登入時會要求註冊 2FA，之後每次都要輸入 2FA
  [ ] （遠端桌面）可以看到 Windows 桌面，文字剪貼簿與檔案上傳／下載符合設定
  [ ] 測試完畢後按「移除全部設定…」，確認 Cloudflare 後台的 Tunnel、DNS 紀錄、
      Access 應用程式與政策、目標（Targets）、路由（Routes）都已刪除


■ 遇到問題時請提供
  1. 部署頁或管理畫面下方「記錄」視窗的截圖
  2. 跳出的錯誤訊息截圖
  3. 若 Tunnel 無法連線：開啟「事件檢視器 → Windows 記錄 → 應用程式」，
     找來源為 cloudflared 的錯誤訊息


■ 檔案位置
  設定檔     C:\ProgramData\CfTunnelTool\config.json
  Token      C:\ProgramData\CfTunnelTool\token.dat（Windows 加密）
  管理程式   C:\Program Files\CfTunnelTool\CfTunnelTool.exe
  連線程式   C:\Program Files\cloudflared\cloudflared.exe
  Windows 服務名稱  Cloudflared


■ 資安提醒
  網站和 API 公開後，任何人都能連線，請務必做好登入驗證。
  只給內部使用的網址，可以在 Cloudflare 後台 → Zero Trust → Access → Applications
  加上登入保護（例如只允許公司 Email 登入）。


■ 紀錄（登入、遠端桌面使用、網路傳輸、程式操作）
  管理畫面按「紀錄…」開啟；被連的電腦在「這台電腦要被遠端連線」畫面按「查看與設定使用紀錄…」；
  使用者端在連線畫面按「紀錄…」（只有程式操作紀錄）。

  紀錄種類：
  - 登入：誰（Email）、何時、從哪個 IP、登入哪個服務、允許或擋下（來源：Cloudflare Access）
  - 遠端桌面使用：哪個 Windows 帳號何時連入、中斷、登出、使用多久、登入失敗（來源：這台電腦的 Windows 事件）
  - 網路傳輸：WARP 使用者連到哪台電腦、大約傳輸多少資料（來源：Cloudflare Gateway 抽樣統計，不含檔案名稱）
  - 程式操作：CfTunnelTool 的部署、修改、移除、連線等所有記錄視窗的內容

  自動收集：
  - Cloudflare 免費方案的登入與網路紀錄只保留 24 小時，請在紀錄視窗按「啟用每小時自動收集」
  - 建立的 Windows 排程以 SYSTEM 身分每小時執行，不需要登入；請讓電腦保持開機
  - 紀錄存在 C:\ProgramData\CfTunnelTool\logs（只有系統管理員能讀取），預設保留 365 天
  - 可依日期與文字篩選，並「匯出 CSV」用 Excel 開啟

  API Token 需要再加兩個權限（精靈權限表標示「紀錄」的兩列）：
    Account → Access: Audit Logs → Read          （登入紀錄）
    Account → Account Analytics → Read           （網路傳輸統計）

  限制：
  - 遠端桌面使用紀錄只記錄執行收集的那台電腦；區網其他電腦要在該電腦上啟用
  - 遠端桌面使用紀錄的來源 IP 是中繼電腦，使用者身分請對照同時間的登入紀錄
  - 瀏覽器方式的檔案傳輸，Cloudflare 沒有提供檔案名稱紀錄
